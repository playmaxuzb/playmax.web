PLAYMAX website demo
- Publish this folder's contents at the root of a GitHub Pages repository; see GITHUB-PAGES.md.
- core.js contains the shared catalog, translations UZ/RU/AF/EN, shipping estimates and app logic.
- viewer3d.js provides live models for MANGU and UFC (loads three.js from the internet).
- assets/ includes product photos, color photos, intro material and 3D textures.
- Orders are sent by the customer through WhatsApp or Telegram to +93 77 990 1111 (no online payment).
- Marketplace posts are saved in the visitor's browser only. Connect a server/database so that
  everyone can see the posts.
